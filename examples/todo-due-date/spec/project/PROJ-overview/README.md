# Todo App 项目概览

## 目的

让 Todo 任务支持截止日期，同时保持日期语义简单、可预测，并让不同端共享同一份契约。

## 当前状态

- **整体状态**：实现中（领域规则已完成并测试，接入层进行中）
- **当前里程碑**：M3 端到端接入

## 目标

| 目标 | 衡量方式 | 状态 |
|---|---|---|
| 日期语义简单可预测 | 规则 R1~R8 全部有测试覆盖 | ✅ 已达成 |
| 各端共享同一份契约 | OpenAPI/SQL/设计资源由各自 Spec 目录维护 | ✅ 已达成 |

## 里程碑

| 里程碑 | 状态 | 完成条件 |
|---|---|---|
